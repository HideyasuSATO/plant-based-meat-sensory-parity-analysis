# Aggregate reference results

`numerical_baselines/` contains selected aggregate outputs retained from the original full revision run and additional sample audit. Its `manifest.csv` maps each baseline to the corresponding generated output. The test in `tests/validate_results.R` compares these files with a new full run.

`manuscript_tables/main/` and `manuscript_tables/supplement/` contain Tables 1-2 and S1-S16 generated by the released exporter and checked against the supplied production proof and Supplement. Confidence bounds are separate columns. Table S16 is in long format.

These are category, endpoint, product, or characteristic-level summaries. No respondent-level records, raw source exports, or intermediate RDS objects are included. The original source data remain subject to their distributor's terms.
